I have developed this website for my KNES 381 class final project. I have custom-built the site, with many features integrated to demonstrate what I have learned.

Heading:
I have made individual tab names and headers at the top of each page. The interactive header will also take the viewer back one page when clicked. Along with that, each page contains embedded links to my social media platforms when clicked. 

Index: 
Most "post" style content contains embedded page links in both the image and using a button below. All linked subpages have been individually created by me with reference to the template elements.html and generic.html page.

Other elements: 
I have incorporated the interactive sidebar into each and every page of my website. It will remain consistent, featuring the same information each time, but I believe this feature was necessary for efficient navigation. Additionally, I have included a contact section at the bottom, and when the email is clicked, it will open an automatic email with a completed subject line for the viewer. 

I hope you enjoy it!
